# فُرن — Restaurant Ordering Demo

ديمو static سريع لمنيو مطعم، سلة، تخصيص أصناف، وإرسال ملخص الطلب إلى واتساب. لا يحتاج framework أو build step أو قاعدة بيانات.

## التشغيل

أبسط طريقة: افتح `index.html` مباشرة بالمتصفح. استخدمنا ملفات JavaScript عادية بدل `import` عمدًا، لأن أغلب المتصفحات تمنع ES modules الخارجية عند الفتح عبر `file://`.

للتجربة الأقرب للنشر شغّل أي static server، مثل:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## تغيير المطعم

1. افتح `js/menu.js` وعدّل معلومات المطعم، رقم واتساب، الأقسام، الأصناف والإضافات.
2. افتح `css/styles.css` وعدّل متغيرات الألوان والمسافات في أول الملف، خصوصًا `--color-primary` و`--color-accent` و`--color-bg`.
3. استبدل الصور داخل `assets/images` مع الحفاظ على أسماء الملفات، أو حدّث خاصية `image` لكل صنف في `menu.js`.
4. حدّث العنوان والوصف ووسوم Open Graph داخل `index.html`.

رقم واتساب التجريبي حاليًا `201000000000`. يجب تغييره قبل إرسال الديمو لعميل حقيقي.

## النشر مجانًا

- GitHub Pages: ارفع المجلد إلى repository، ثم فعّل Pages من Settings → Pages واختر الفرع الرئيسي.
- Netlify: اسحب المجلد إلى Netlify Drop؛ لا يوجد build command.
- Vercel: استورد المشروع كـ Other/Static، واترك Build Command فارغًا واجعل Output Directory هو `.`.

## ملاحظات الأداء

- صورة الـhero محلية، responsive، مهيأة بـ AVIF و`fetchpriority="high"`.
- بقية الصور lazy-loaded ولها أبعاد صريحة لتقليل CLS.
- HTML/CSS/JS بلا مكتبات إنتاجية أو خطوط خارجية.
- الصور التجريبية من Unsplash ويجب استبدالها بصور المطعم الأصلية عند الاتفاق.

## قبل التسليم لعميل

- جرّب رقم واتساب الحقيقي من هاتف فعلي.
- راجع الأسعار، مناطق ورسوم التوصيل، المواعيد والعنوان.
- اختبر صور المطعم على شبكة موبايل بطيئة.
- نفّذ Lighthouse على رابط HTTPS منشور؛ القياسات على `file://` أو localhost لا تمثل الاستضافة الحقيقية دائمًا.
